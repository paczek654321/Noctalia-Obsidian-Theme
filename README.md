# About
This repository contains a Noctalia user template for generating an Obsidian theme as well as a theme to be modified by it.
# Usage
1. Install the Obsidian theme
1.1. Put the `Noctalia` folder in your vaults themes directory
1.2. Select the theme in `Obsidian Settings -> Appearance -> Themes`
2. Use the Noctalia user template
2.1. Copy the `user-templates.toml` file to `~/.config/noctalia/user-templates.toml`
2.2. Go to `Noctalia settings -> Color Scheme -> Templates -> Enable user templates` (set to enabled)
